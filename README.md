# Чудо Обувь

Учебный проект по ПМ.02 «Осуществление интеграции программных модулей». Период практики: 19.10.2026 - 24.10.2026.

Программа позволяет выбрать обувь из каталога и оформить заказ. Сделана на C# и WPF с использованием .NET Framework 4.8, Entity Framework 6 и MS SQL Server. Для работы с базой используется модель EDMX (Database First).

## Возможности

- Просмотр товаров с фотографиями, описанием, ценой и остатками.
- Вход по логину. Пароль не требуется по условию задания.
- Поиск, отбор по категории и сортировка по цене.
- Выбор размера, добавление в корзину и оформление заказа.
- Просмотр и удаление заказов менеджером и администратором.
- Изменение даты и удаление отдельных позиций администратором.

Гость может просматривать каталог. После входа клиенту доступны поиск и оформление заказа. Менеджер также работает с заказами клиентов, а администратор может их редактировать.

Если модель не заказывали в прошлом календарном месяце, на неё действует скидка 25%. При сохранении заказа программа ещё раз проверяет остатки. Удаление заказа возвращает товары на склад.

## Что нужно для запуска

- Windows 10 или 11.
- .NET Framework 4.8.
- SQL Server Express LocalDB или другой экземпляр MS SQL Server.
- Для сборки: .NET SDK и .NET Framework 4.8 Developer Pack.

В репозитории находится код. Учебные таблицы, фотографии, готовая программа и отчёт хранятся отдельно.

### Ресурсы задания

Для сборки нужны изображения из [Приложения 2 к заданию](https://bom.firpo.ru/Public/6397). Папку `Images`, заглушку `picture.png`, логотип и иконку нужно разместить в `src/ShoeStore.App/Assets`. Логотип используется под именем `logo.png`, иконка — `store.ico`.

Учебная база с данными передаётся отдельно от репозитория.

### Сборка

В папке проекта выполнить:

```powershell
dotnet build ShoeStore.sln -c Release
dotnet build src/ShoeStore.App -c Release -o release/final
```

Запускать `ShoeStore.App.exe` из папки `release/final`. Библиотеки DLL и папка `Assets` должны оставаться рядом с программой. SQL-скрипты из папки `Database` нужны для подготовки базы; приложение не выполняет их при запуске.

Для запуска требуется готовая база `ShoeTest` на `(localdb)\MSSQLLocalDB` с проверкой подлинности Windows. Схема приведена в `database/schema.sql`. Логины указаны в учебной таблице пользователей.

Для подключения к другому серверу нужно положить рядом с программой файл `connection-string.txt`. Пример находится в `database/connection-string.example.txt`.

## Проверки

После подготовки данных проверки запускаются командой:

```powershell
dotnet run --project tests/ShoeStore.Checks -c Release
```

В последнем прогоне прошли 29 проверок. Проверялись роли пользователей, поиск, скидки, оформление и удаление заказов, нехватка товара и одновременная покупка последней пары. Проверки используют отдельную временную базу. Протокол сохраняется в `docs/test-results.txt`.

## Данные задания

Загружены 31 модель обуви, 92 позиции по размерам, 20 пользователей и 10 заказов с 30 строками. Половинные размеры сохранены.

При импорте убираются лишние пробелы. Сокращённое название чёрных классических туфель сопоставляется с полным названием той же модели. Остатки из исходной таблицы считаются доступными: старые заказы повторно их не уменьшают.

Базовая цена хранится в `Products.price` как `decimal(18,0)`, размер в `Sizes.size` — как `float`. В `Products` находятся независимые ссылки `categoryId` и `subcategoryId`. Между `Categories` и `Subcategories` связи нет. Состав заказа хранится в `OrderItems` со ссылкой на `StockItems`. Цена в строке заказа отдельно не хранится; суммы рассчитываются по текущим ценам и скидкам. Фотографии и логотип взяты из материалов задания. Оплата и доставка в проект не входят.
