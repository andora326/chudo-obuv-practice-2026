# Чудо Обувь

Приложение для выбора и заказа обуви. Учебная практика по ПМ.02, период **19.10.2026–07.11.2026**.

## Что реализовано

- Каталог с фотографиями, составом, производителем, ценой и остатками.
- Вход по логину без пароля согласно заданию. Четыре режима: гость, клиент, менеджер, администратор.
- Поиск по названию и описанию, фильтр категории, сортировка по цене. Все условия работают совместно.
- Выбор размера (включая половинные), корзина, изменение количества и подтверждение заказа.
- Заказы клиентов для менеджера и администратора. Выбор клиента при создании, просмотр состава, удаление с возвратом остатка.
- Администратор изменяет дату и удаляет отдельные позиции заказа.
- Скидка 25% на модели, у которых не было заказов в предыдущем календарном месяце относительно текущей даты компьютера.
- Транзакции и повторная проверка остатков при сохранении; защита от одновременной покупки последней пары.

## Запуск

Готовая сборка, отчёт и исходные учебные данные хранятся локально и не публикуются в этом репозитории. Требуются Windows 10/11 x64, .NET Desktop Runtime 9 x64 и Microsoft SQL Server Express LocalDB (либо другой экземпляр SQL Server).

Перед сборкой с учебными данными скачайте официальные приложения к заданию: https://bom.firpo.ru/Public/6397. Распакуйте таблицы и изображения Приложения 2 в `../materials/data` относительно корня проекта. Установите Python-пакет `openpyxl` и запустите `python tools/import_data.py`. Он создаст локальные `database/seed.sql` и `src/ShoeStore.App/Assets`. Эти файлы исключены из Git.

При первом запуске база автоматически создаётся из SQL. Используется база `ChudoObuvPractice` на `(localdb)\MSSQLLocalDB` с проверкой подлинности Windows. Для другого экземпляра SQL Server создайте `connection-string.txt` рядом с программой по примеру `database/connection-string.example.txt`. Логины берутся из файла пользователей в официальных ресурсах, пароль по заданию не нужен.

## Сборка и проверки

Нужен .NET SDK 9. Из корня проекта:

```powershell
dotnet build ShoeStore.sln -c Release
dotnet run --project tests/ShoeStore.Checks -c Release
dotnet publish src/ShoeStore.App -c Release -r win-x64 --self-contained false -o release/sqlserver-windows-x64
```

28 проверок используют отдельную временную базу и фиксированную дату. Они проверяют импорт, роли, скидки на границе месяца и года, атомарность заказа, возврат остатка и конкурентную покупку. Результаты прогона сохраняются локально в `docs/test-results.txt`.

## Структура

- `src/ShoeStore.App` - окна WPF, оформление и навигация.
- `src/ShoeStore.Core` - модели, запросы и правила работы с заказами.
- `database/schema.sql` - схема Microsoft SQL Server с ключами и ограничениями.
- `database/seed.sql` - локальный результат импорта, не публикуется.
- Полный скрипт базы с данными хранится локально.
- `tests/ShoeStore.Checks` - исполняемые проверки основных сценариев.
- `docs` - руководство и описание требований; отчёт, схемы и скриншоты остаются локально.
- `release/sqlserver-windows-x64` - локальная готовая сборка с учебными данными.
- `tools/import_data.py` - повторное преобразование исходных XLSX в SQL.

## Исходные данные и принятые решения

Задание: КИМ 09.02.07-2-2027, базовый уровень, компания «Чудо Обувь». Материалы: https://bom.firpo.ru/Public/6397. Импортированы 31 модель, 92 позиции по размерам, 20 пользователей, 10 заказов (30 строк), 35 размеров.

При импорте исправляются неразрывные и лишние пробелы. Сокращённое название «Черные туфли в классическом стиле» в остатках сопоставляется с полным названием той же модели и производителя. Исходные остатки считаются уже доступными; исторические заказы повторно их не уменьшают. Деньги хранятся в копейках, итог заказа рассчитывается по сохранённым ценам его строк.

Программа предназначена для учебного локального использования. Вход без пароля реализован по условию задания. Оплата, доставка, серверная авторизация и настройка общего сетевого сервера в объём этой работы не входят. Файл `.dt` не требуется: приложение разработано на C#, а не на платформе 1С.

Фото, логотип, иконка и учебные данные взяты из ресурсов задания и используются для выполнения практики.
